## Current strongest candidate

`maintenance.workorders` is the only current surface combining a production API, contextual copilot preview, local read-only UI actions, chart/table/drawer synchronization, and trace-like metadata. It should be the first Phase B target, but only after stable route and region IDs are documented and enforced.
